# لعبة مغامرات تطوّرها بالذكاء الاصطناعي (Unity + OpenRouter)

لعبة مغامرات ثلاثية الأبعاد تلعبها بنفسك، وبنفس الوقت **تطوّرها بالكلام**: تكتب للذكاء الاصطناعي
«ضيف وحوش»، «سوي قلعة ومهمة»، «ضيف شخصية تحجي وياي»، «حولها 2D مثل ماريو»... فيضيفها للعبة فورًا،
**وتنحفظ** وترجع وياك كل مرة تفتح اللعبة.

## اللعب

| المفتاح | الوظيفة |
|---|---|
| WASD أو الأسهم | حركة |
| Space | قفز (واقفز فوق الوحوش حتى تقتلهم) |
| F | ضرب الوحوش القريبة |
| E | كلام مع الشخصيات |
| Enter | اكتب طلب للذكاء الاصطناعي، وEnter ثانية ترسله وترجع للعب |

على الموبايل تطلع أزرار حركة وقفز وضرب وكلام (أخفِ لوحة المحادثة حتى تلعب).

المرحلة الأولى جاهزة: اجمع 5 عملات، احجي ويه الشيخ حسن، انتبه من الحمم والوحوش، وروح للبوابة البنفسجية.

## تطوير اللعبة بالذكاء الاصطناعي

- كل طلب تكتبه يتنفذ فورًا وينحفظ كتعديل على المرحلة.
- **تراجع**: يلغي آخر تعديل. **إعادة اللعب**: تبدأ المرحلة من جديد بكل تعديلاتك.
- من ⚙ الإعدادات: رجّع المرحلة الافتراضية، أو ابدأ مرحلة فاضية وابنِ من الصفر.
- **نسخ المرحلة (JSON)**: تنسخ مرحلتك. الصقها بملف `Assets/Resources/DefaultLevel.json` حتى تصير هي المرحلة الأساسية بأي نسخة تبنيها من اللعبة.

الذكاء الاصطناعي يكدر يضيف: عملات وجواهر ومفاتيح وصحة، وحوش (سرعة، ضرر، صحة)، شخصيات بحوار،
مهمات (اجمع، اقتل، اوصل، احجي)، بوابة الفوز، حمم وفخاخ، منصات ومنصات متحركة، مباني من أشكال،
جاذبية وليل ونهار، تكبير سرعة وقفزة اللاعب، وتحويل اللعبة 2D أو 3D.

## التشغيل

1. ثبّت **Unity Hub** و Unity 6 (أو أي إصدار من 2021.3 فما فوق).
2. Unity Hub ← **Add** ← اختر مجلد `unity-sim` هذا ← افتحه (إذا سألك عن الإصدار اختر الموجود عندك).
3. عند أول فتح ينشئ المشروع مشهد `Assets/Scenes/AISim.unity` تلقائيًا (أو من القائمة **AI Sim ← Create Scene**).
4. اضغط **Play**.

## المفتاح (API key)

المستودع **عام**، لذلك المفتاح غير مرفوع على GitHub (أي مفتاح يُرفع لمستودع عام تسحبه البوتات خلال دقائق وتصرف رصيد المحفظة).
ضعه بإحدى الطريقتين:

- **داخل التطبيق:** ⚙ الإعدادات ← الصق المفتاح ← حفظ. يُحفظ على جهازك فقط.
- **مضمّن بالتطبيق:** أنشئ ملف `Assets/Resources/OpenRouterKey.txt` واكتب فيه المفتاح فقط (سطر واحد).
  الملف مستثنى من Git عبر `.gitignore`، ويدخل ضمن التطبيق عند البناء فيشتغل مباشرة بلا إعدادات.

> تنبيه: أي مفتاح مضمّن داخل ملف APK/EXE يمكن استخراجه. لا تنشر النسخة المبنية للعامة،
> وحدد سقف صرف للمفتاح من openrouter.ai ← Keys ← Edit ← Credit limit.

الرصيد المتبقي بالمحفظة يظهر أعلى لوحة المحادثة ويتحدث بعد كل طلب.

## النموذج

الافتراضي `openai/gpt-4o-mini` (رخيص وسريع). غيّره من الإعدادات لأي اسم من [openrouter.ai/models](https://openrouter.ai/models).
إذا تعطل النموذج المختار يتحول الطلب تلقائيًا إلى `openrouter/auto`.

## أمثلة طلبات

- ضيف 3 وحوش حمر يلاحقوني بس يكونون أبطأ مني
- سوي قلعة بيها 3 مفاتيح ومهمة اجمع المفاتيح وبعدين روح للبوابة
- ضيف شيخ يحجي وياي ويعطيني مهمة أقتل الوحوش
- سوي بحيرة حمم وجسر فوكها وعملات على الجسر
- حولها 2D مثل ماريو وسوي منصات أقفز عليها
- خليها ليل وجاذبية القمر وخليني أقفز أعلى

## الكاميرا

- اسحب بالماوس/الإصبع خارج اللوحة لتدوير الكاميرا حول الشخصية، والعجلة أو أزرار + − للتكبير.
- «كاميرا» يرجّع المنظر خلف الشخصية، «إخفاء» يخفي لوحة المحادثة.

## كيف يشتغل

| الملف | الوظيفة |
|---|---|
| `Assets/Scripts/SimBootstrap.cs` | يبني اللعبة تلقائيًا عند Play (بلا إعداد مشهد) |
| `Assets/Scripts/SimGame.cs` | اللاعب، الصحة والنقاط، المهمات، الحوار، الواجهة، أزرار الموبايل |
| `Assets/Scripts/SimPlayer.cs` | حركة الشخصية والقفز |
| `Assets/Scripts/SimEntities.cs` | العملات، الوحوش، الشخصيات، البوابة، الحمم |
| `Assets/Scripts/SimLevel.cs` | حفظ تعديلاتك على المرحلة والتراجع عنها |
| `Assets/Resources/DefaultLevel.json` | المرحلة الأولى (نفس صيغة أوامر الذكاء الاصطناعي) |
| `Assets/Scripts/OpenRouterClient.cs` | الاتصال بـ OpenRouter والرصيد |
| `Assets/Scripts/SimPrompt.cs` | تعليمات النموذج (مصمم اللعبة) وقائمة الأوامر المسموحة |
| `Assets/Scripts/SimWorld.cs` | ينفذ الأوامر: spawn, move, physics, gravity, camera, text… |
| `Assets/Scripts/SimBehaviours.cs` | الحركات: دوران، قفز، مدار، تجوال، لحاق، نبض، ألوان |
| `Assets/Scripts/SimChatUI.cs` | لوحة المحادثة والإعدادات |
| `Assets/Scripts/ArabicText.cs` | تشكيل الحروف العربية واتجاهها (Unity لا يدعمها افتراضيًا) |

مع كل رسالة يُرسل للنموذج وصف العالم الحالي (الأجسام، أدوارها، مكان اللاعب وصحته ونقاطه والمهمة)، فيرد بـ JSON فيه رد قصير وقائمة أوامر تنفذها Unity وتنحفظ بالمرحلة.

## خط عربي أجمل (اختياري)

ضع أي خط عربي TTF باسم `ArabicFont.ttf` داخل `Assets/Resources/` ويُستخدم تلقائيًا للواجهة والنصوص.
