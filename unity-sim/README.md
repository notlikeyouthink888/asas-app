# محاكاة Unity بالذكاء الاصطناعي (OpenRouter)

تكتب بالعربي (أو العراقي) أي شي تريده، والذكاء الاصطناعي عبر OpenRouter يسويه بالمحاكاة:
يبني أجسام، يحركها، يفعّل الفيزياء، يغير الجاذبية والسما والضوء، يحول الكاميرا 2D أو 3D، يكتب نصوص بالمشهد...

## التشغيل

1. ثبّت **Unity Hub** و Unity 6 (أو أي إصدار من 2021.3 فما فوق).
2. Unity Hub ← **Add** ← اختر مجلد `unity-sim` هذا ← افتحه (إذا سألك عن الإصدار اختر الموجود عندك).
3. عند أول فتح ينشئ المشروع مشهد `Assets/Scenes/AISim.unity` تلقائيًا (أو من القائمة **AI Sim ← Create Scene**).
4. اضغط **Play**.

## المفتاح (API key)

المستودع **عام**، لذلك المفتاح غير مرفوع على GitHub (أي مفتاح يُرفع لمستودع عام تسحبه البوتات خلال دقائق وتصرف رصيد المحفظة).
ضعه بإحدى الطريقتين:

- **داخل التطبيق:** ⚙ الإعدادات ← الصق المفتاح ← حفظ. يُحفظ على جهازك فقط.
- **مضمّن بالتطبيق:** أنشئ ملف `Assets/Resources/OpenRouterKey.txt` واكتب فيه المفتاح فقط (سطر واحد).
  الملف مستثنى من Git عبر `.gitignore`، ويدخل ضمن التطبيق عند البناء فيشتغل مباشرة بلا إعدادات.

> تنبيه: أي مفتاح مضمّن داخل ملف APK/EXE يمكن استخراجه. لا تنشر النسخة المبنية للعامة،
> وحدد سقف صرف للمفتاح من openrouter.ai ← Keys ← Edit ← Credit limit.

الرصيد المتبقي بالمحفظة يظهر أعلى لوحة المحادثة ويتحدث بعد كل طلب.

## النموذج

الافتراضي `openai/gpt-4o-mini` (رخيص وسريع). غيّره من الإعدادات لأي اسم من [openrouter.ai/models](https://openrouter.ai/models).
إذا تعطل النموذج المختار يتحول الطلب تلقائيًا إلى `openrouter/auto`.

## أمثلة

- سويلي بيت بي باب وشباك وشجرتين يمه
- طيّح 30 كرة ملونة من السما وخليهن ينطّن
- سوي نظام شمسي والكواكب تدور حول الشمس
- حولها 2D وسوي هرم من 15 مكعب وفجّره
- خليها ليل وجاذبية القمر
- خلي الكاميرا تلحك السيارة

## التحكم

- اسحب بالماوس/الإصبع خارج اللوحة لتدوير الكاميرا، والعجلة أو أزرار + − للتكبير.
- «كاميرا» يرجّع المنظر، «إخفاء» يخفي لوحة المحادثة.

## كيف يشتغل

| الملف | الوظيفة |
|---|---|
| `Assets/Scripts/SimBootstrap.cs` | يبني المحاكاة تلقائيًا عند Play (بلا إعداد مشهد) |
| `Assets/Scripts/OpenRouterClient.cs` | الاتصال بـ OpenRouter والرصيد |
| `Assets/Scripts/SimPrompt.cs` | تعليمات النموذج وقائمة الأوامر المسموحة |
| `Assets/Scripts/SimWorld.cs` | ينفذ الأوامر: spawn, move, physics, gravity, camera, text… |
| `Assets/Scripts/SimBehaviours.cs` | الحركات: دوران، قفز، مدار، تجوال، لحاق، نبض، ألوان |
| `Assets/Scripts/SimChatUI.cs` | لوحة المحادثة والإعدادات |
| `Assets/Scripts/ArabicText.cs` | تشكيل الحروف العربية واتجاهها (Unity لا يدعمها افتراضيًا) |

مع كل رسالة يُرسل للنموذج وصف العالم الحالي (الأجسام، أماكنها، ألوانها)، فيرد بـ JSON فيه رد قصير وقائمة أوامر تنفذها Unity.

## خط عربي أجمل (اختياري)

ضع أي خط عربي TTF باسم `ArabicFont.ttf` داخل `Assets/Resources/` ويُستخدم تلقائيًا للواجهة والنصوص.
